# Support

Use public GitHub Issues for this adapter for:

- Antigravity configuration/command defects,
- validation failures,
- documentation drift.

For security reports, use a private advisory at the repository security page.
Do **not** open public issue text for exploit details.

When filing an issue, include:

- OS and profile,
- relevant command chain,
- module commit SHA,
- sanitized outputs from `scripts/validate.sh` or equivalent validate scripts.
